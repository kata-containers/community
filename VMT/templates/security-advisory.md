# Security advisory template

Copy from below, paste into the GHSA (overwriting the original report) and replace the _italics_.

## Template

```md
_One paragraph summary of the problem, description at a high level._

## Detailed description

_One paragraph explaining the attack vector and its prerequisites. Don't provide a full PoC!_

_One paragraph explaining the affected parties._

_One paragraph explaining the affected configurations (Kata/CoCo, Hypervisor, image flavour, etc.)._

## Patches and workarounds

This vulnerability has been patched with _vX.Y.Z_.

_If applicable: a configuration change or other methods to prevent the attack._

## Notes

_Thank-you note to the reporters, including reporters of duplicates._
_This is also the place for putting any information the reporters wanted to surface, such as their comany affiliation._
_It's ok to omit this section if nothing applies._

```

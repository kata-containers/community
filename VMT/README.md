# Vulnerability Management Team

The Kata Containers Vulnerability Management Team (VMT) is responsible for the lifecycle of vulnerability reports, embargoed fixes and security advisories.

## Reporting vulnerabilities

Please follow the process outlined in <https://github.com/kata-containers/kata-containers/blob/main/SECURITY.md>.

## The VMT

The following documents outline the internal processes for vulnerability handling at Kata.
They are not required reading for reporters, but document the responsibilities of the VMT.

- The [VMT charter](VMT-charter.md) describes how the VMT is constituted and what responsibilities lie with the VMT.
- The [VMT members list](VMT-members.md) contains the up-to-date list of VMT members.
- The [VMT](VMT.md) document describes the vulnerability management process in detail.
